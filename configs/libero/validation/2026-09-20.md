checkpoint using the implementation in

## Verification and fixes

- Loaded all 893 weight tensors through the actual public `ModelBuilder` and
  `Tau0VLAPolicy`, warmed up on GPU, and exercised the dedicated HTTP endpoint.
  Real inference returned finite `(10, 7)` actions. Resetting seed 7 and
  repeating the same input gave exactly equal actions in the tested eager mode.
- Checked the actual export against the training route: normalized states and
  sparse state/action masks match, inactive dimensions remain zero, and native
  delta actions round-trip through normalization/rot6d/restoration, including
  gripper values, without subtracting the current state a second time.
- Passed 10 regression tests covering the existing LIBERO contracts, stale
  field metadata, training/serving parity, square-image resize parity,
  contiguous masks, hardware EEF rejection, malformed/nonfinite action chunks,
  initial-state offsets, error accounting, renderer cleanup, and overwrite protection.
- Compared real G1 example-data encoding, action restoration, and semantic
  slices against PR base `a40816c07f118b610d2a4fd3e1413012a46d1c47`: outputs
  are byte-identical. The hardware server still accepts joint-only specs and
  rejects EEF specs; no physical robot execution was performed.
- Removed the simulation client's import of the training/LeRobot stack while
  preserving image preprocessing. Cross-environment Pillow 12.3.0 / 11.1.0
  resize outputs were also pixel-identical. Added policy RNG reset, weight/code metadata,
  per-episode/per-task records, initial-state offsets, failure exit status, and
  renderer cleanup. No model parameters or normalization values were changed.

Initial startup exposed missing OpenGL loader libraries and PyTorch 2.6's
weights-only default rejecting LIBERO's NumPy initial-state files. These were
resolved in the isolated evaluation setup before the counted rollouts. See
the guide for the loader packages and the simulator-only setting for trusted
official assets. Startup failures are not policy rollouts.

## Remaining limitations

Five initial states per task provide a coarse check, not a precise estimate
or an exact reproduction of the author's 2,000-episode result. This run fixes
both simulator and policy seeds and uses eager inference; other seeds,
optimized inference, and physical hardware were not validated here.

The evaluated export is published at
[`sii-research/tau-0-vla-libero`](https://huggingface.co/sii-research/tau-0-vla-libero),
revision `48e12c55f26858ac6633b905642adbfb4ee920f0`. Anonymous access was verified on 2026-09-20:
the uploaded weight SHA-256 matches the evaluated export, all configuration
and normalization files match their checksums, and a weight byte-range download
matches the local file.

Raw logs, package inventories, checks, and all rollout videos are retained in
the maintainer's local validation artifact bundle; the JSON above publishes
the summary; the CSV publishes episode results and video identities. The videos themselves are not hosted in
this repository. PR #4 remains open for review and has not been merged.
